# 好朋友地圖 Period Pal Map

公衛學院試辦的生理用品即時地圖。同學掃描貼在補給點旁的 QR Code，一鍵回報「充足／剩少量／已用完」，其他人打開網頁就知道哪裡有。

本專案為 115-1 NTU Challengers #PBL #AI Agent 個別型提案。

## 目前進度

- [x] 網頁原型：即時總覽、掃碼回報頁、各點 QR Code 產生
- [x] 補給點清單：公衛學院大樓 1 到 7 樓，每層一個女廁點
- [ ] 實地確認各樓層補給點的實際位置與補貨窗口
- [ ] 中繼服務：接收回報並寫入 Notion 資料庫
- [ ] Claude Agent：定時判斷狀態、通知補貨、產出每週摘要
- [ ] 每週匿名統計匯出到本 repo 的 `data/`，作為公開紀錄

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個網頁（GitHub Pages 直接發布） |
| `data/` | 每週匿名統計（之後由 Agent 自動寫入） |

## 要改設定的地方

打開 `index.html`，搜尋「設定區」：

- `CONFIG.apiUrl`：中繼服務網址。留空時為示範模式，回報只存在使用者自己的瀏覽器。
- `LOCS`：補給點清單。每個點的 `id` 會出現在 QR Code 網址裡（例如 `#r-cph-2f`），QR Code 貼出去後就不要再改。

## 網址格式

- 即時總覽：`https://<帳號>.github.io/period-pal-map/`
- 某個點的回報頁（QR Code 內容）：`https://<帳號>.github.io/period-pal-map/#r-cph-2f`
- 產生所有 QR Code：`https://<帳號>.github.io/period-pal-map/#qr`

## 隱私原則

- 回報不需要登入，不收集姓名、學號、照片或任何可辨識個人的資料。
- 公開到 GitHub 的只有每週彙總統計（各點回報次數、用完次數、盤點用量），不含單筆回報時間戳記。

## 判斷規則（原型版，之後交給 Agent）

- 以最新一筆回報為準。
- 一小時內有人說用完、有人說還有 → 標示「回報不一致」。
- 超過 6 小時沒人回報 → 標示「待確認」。
