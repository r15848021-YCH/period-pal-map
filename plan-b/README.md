# 好朋友 Pal（Plan B）

好朋友地圖的延伸發想：把校園生理用品地圖擴充成女性健康 App，加上經期紀錄與預測、心情紀錄。主計畫（根目錄的 `index.html`）不受影響。

| 檔案 | 用途 |
| --- | --- |
| `prototype/index.html` | 可操作的網頁原型：今天／經期／心情／補給地圖四個分頁 |
| `架構圖.png`、`時程圖.png` | Plan B 計畫書的圖一、圖二 |

## 原型怎麼看

直接用瀏覽器打開 `prototype/index.html`。一開始是示範資料，按「清空，開始記錄我自己的」就能用自己的資料試。

## 資料放在哪

- 經期、症狀、心情與備註：只存在瀏覽器的 localStorage，不上傳。「今天」頁可以複製備份或一鍵刪除。
- 補給地圖回報：原型裡同樣只存在本機；正式版沿用主計畫的 Cloudflare Worker＋D1＋LINE Bot。

## 規則（原型版，正式版交給 Claude Agent 寫成文字）

- 預測：最近 6 個週期平均（排除 15 天以下、60 天以上）；資料不足時用 28 天、經期 5 天。
- 提醒：週期少於 21 天或多於 35 天、長短相差 8 天以上、經期超過 7 天、兩次以上記錄「經痛很嚴重」、比預估晚 7 天以上。
- 心情：比較經期中、經前一週、其他日子的平均心情。
- 預估僅供參考，不能當作避孕依據，也不是醫療診斷。
